# 검색 노출(SEO)

앱(Flutter 웹)은 화면을 캔버스에 그려 구글이 글자를 읽지 못한다. 검색에 걸리는 글은
아래 정적 페이지와 `web/index.html`의 머리말뿐이다.

| 주소 | 내용 | 만드는 곳 |
| --- | --- | --- |
| `/` | 제목·설명, 사이트 이름(Baskit/바스킷)·로고 구조화 데이터 | `web/index.html` |
| `/about/` | 서비스 소개, 자주 묻는 질문(FAQ 구조화 데이터) | `tools/build-seo-pages.js` |
| `/kbl/` | KBL 10개 구단 | 〃 |
| `/kbl/{팀}/` | 구단별 선수 명단(SportsTeam 구조화 데이터) | 〃 |
| `sitemap.xml`, `robots.txt` | 위 주소 목록 | 〃 / `web/robots.txt` |

선수 명단이 바뀌면(시즌 시작, 트레이드) `node tools/build-seo-pages.js` 후 배포한다.

## 노리는 검색어

- **서비스 이름**: Baskit, 바스킷, 바스킷 앱, Baskit 농구
- **기능**: 농구 실시간 경기, 농구 실시간 점수, KBL 실시간, KBL 일정, KBL 경기 결과,
  KBL 순위, 농구 순위, KBL 선수 기록, 농구 기록, 박스스코어, 문자중계, 농구 승부예측,
  농구 커뮤니티, 농구 앱, 농구 뉴스, KBL 뉴스, NBA 뉴스, 프로농구 앱
- **구단(10)**: 서울 SK 나이츠, 안양 정관장 레드부스터스, 원주 DB 프로미, 창원 LG 세이커스,
  부산 KCC 이지스, 수원 KT 소닉붐, 대구 한국가스공사 페가수스, 고양 소노 스카이거너스,
  울산 현대모비스 피버스, 서울 삼성 썬더스 (+ "선수 명단", "경기 일정")
- **선수(192)**: `/kbl/{팀}/`의 선수 이름 + "소속팀", "등번호", "포지션"

"농구", "NBA"처럼 큰 검색어는 네이버·KBL·NBA 공식 사이트가 차지하고 있어 상위 노출을
기대하기 어렵다. 서비스 이름과 "구단·선수 + 명단/기록"처럼 좁은 검색어부터 노린다.
한국은 네이버 비중이 커서 네이버 서치어드바이저에도 사이트를 등록한다.
